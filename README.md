# 12bottles Balatro Test Mod

Hi! This is a mod I am writing to learn how to mod Balatro.

As of writing, this mod has 8 new unique jokers and 1 new deck.

By default, there are 5 extra jokers and 2 extra decks included in the mod, but not loaded in. This is due to them either being copied from a tutorial, or implemented in some other way.
Also hidden by default is a rough implementation of X Joker/s every Ante, as seen on [Roffle's Youtube channel](https://www.youtube.com/@RoffleLite), since there is currently no public release of the mod, and I wanted to play it.

This project was started by following the "[**A Beginner's Guide to Making Balatro Mods**](https://www.youtube.com/playlist?list=PLC52vBRlSqLtmTyhEvU8k9bKbYI_os7tM)" tutorial,
by [theAstra](https://www.youtube.com/@theAstra_).

If you happen to stumble upon this, and have experience in Balatro modding, feel free to have a look through and suggest improvements.
