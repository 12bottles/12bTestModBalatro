# 12bottles Balatro Test Mod

Hi! This is a mod I am writing to learn how to mod Balatro.

This was started by following the [**A Beginner's Guide to Making Balatro Mods**](https://www.youtube.com/playlist?list=PLC52vBRlSqLtmTyhEvU8k9bKbYI_os7tM) tutorial,
by [theAstra](https://www.youtube.com/@theAstra_). I've also added in my own features, some unique and others inspired by other mods.

If you happen to stumble upon this, and have experience in Balatro modding, feel free to have a look through and suggest improvements.
